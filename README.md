# poweragent

> ⚠️ **Early-stage prototype** — exploratory work in progress.

A small experiment in driving a GitHub Copilot agent from PowerShell.
The goal is a thin PowerShell wrapper that scripts agent interactions
on Windows without a full application around it.

## Status

This repo is a placeholder for an idea still being shaped. For a more
complete take on the same theme, see
[**psghagent**](https://github.com/enu235/psghagent) — a Windows desktop
chat app fronting GitHub Copilot for non-technical business users.
